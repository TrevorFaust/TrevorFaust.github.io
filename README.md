# Trevor Faust — Portfolio

Personal site for projects, about, and contact links.

## Local development

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` build and publish via GitHub Pages (see `.github/workflows/deploy.yml`).

## Edit content

Project copy, links, and about text live in `src/data/site.ts`.
